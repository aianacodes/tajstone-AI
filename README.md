# 🕌 TajStone AI
AI for Taj Mahal Preservation - Stone Deterioration Detection

🚀 **Live App:** https://tajstone-ai-su2gtqe35sjpmywe9zajbm.streamlit.app/

## Features
- Upload stone image
- Detect deterioration level (Low / Medium / High)
- Conservation recommendations
- Preventive measures for ASI

## Why this matters?
Taj Mahal's white marble is turning yellow due to pollution and aging. This AI helps detect damage early.
